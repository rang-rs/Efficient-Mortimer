# Efficient Mortimer

Highlights efficient Mortimer task choices and recommends skips for post-99 Slayer using solver-backed lists from [ehp.gg](https://ehp.gg/slayer).

Pick between Main, Ironman, Ironman Barrage, or a custom list tailored to your account on ehp.gg.

Recommended blocks for the built-in lists: Cave horrors and Hydras.

To import a custom list:

1. Open [ehp.gg/slayer](https://ehp.gg/slayer). Optionally import your stats and bank for a more accurate solve.
2. Click 'Run Solver'.
3. Click 'Copy for RuneLite'.
4. In Efficient Mortimer, select 'Custom' and expand 'Custom import'. Paste the list, then click outside the field to apply.
